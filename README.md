# LLM Basics

A concept-first learning library for practical LLM engineering and NVIDIA Gen AI LLM certification preparation.

Live site: https://llm-learning.inprogress.fyi

## What is inside

The course moves from LLM fundamentals through prompting/RAG, data preparation, optimization, fine-tuning, evaluation, GPU systems, deployment, reliability, and safety. Every chapter includes explanations, practical decision points, a mini-lab, checkpoint questions, and selected external learning resources.

## Development

```bash
npm install
npm run start
```

## Production checks

```bash
npm run typecheck
npm run build
```

The site is built with [Docusaurus](https://docusaurus.io/) and deployed through Vercel.
